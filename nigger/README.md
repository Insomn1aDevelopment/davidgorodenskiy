# Давид Городенский

Фронтенд из нового архива самодостаточен: разметка, стили и клиентский JavaScript находятся в `index.html`; изображения — в `img/`.

## Запуск

Из корня репозитория запустите `npm start`, либо из этой папки — `node server.js`. Нужен Node.js 20 или новее. Сторонние пакеты не нужны.

## Быстрая отдача статики

Сервер загружает страницу и изображения в память при старте, отдаёт сжатый gzip HTML, проверяет ETag и поддерживает `HEAD`/`304`. Для новой версии ресурсов перезапустите сервер.

## API

- `GET /api/health` — проверка доступности.
- `POST /api/feedback` — сохранить отзыв. JSON-тело: `{"message":"Текст отзыва"}`. Максимум 1000 символов; слишком большие запросы отклоняются.

Отзывы остаются в `data/feedback.json`. Записи сериализуются через асинхронную очередь и сохраняются атомарной заменой файла.
