# Давид Городенский

Фронтенд самодостаточен: разметка, стили и клиентский JavaScript находятся в `index.html`; изображения — в `img/`.

## Запуск

Из корня репозитория запустите `npm start`, либо из этой папки — `node server.js`. Нужен Node.js 22.13 или новее (встроенный модуль `node:sqlite`). Сторонние пакеты не нужны. Порт задаётся переменной `PORT` (по умолчанию 3000).

## Быстрая отдача статики

Сервер загружает страницу и изображения в память при старте, отдаёт сжатый gzip HTML, проверяет ETag и поддерживает `HEAD`/`304`. Для новой версии ресурсов перезапустите сервер.

## База данных

Данные хранятся в SQLite-файле `data/site.db` (создаётся при первом запуске; папку можно сменить переменной `DATA_DIR`). Таблицы:

- `candles` — зажжённые свечи памяти, одна на посетителя;
- `votes` — голоса «весов истории», один на посетителя для каждой загадки (повторный голос меняет выбор);
- `feedback` — отзывы. Старый `data/feedback.json`, если он есть, импортируется при первом запуске.

Посетитель определяется случайным идентификатором, который браузер хранит в `localStorage` (`dg-uid`). Если сервер недоступен, свеча и голос сохраняются только на этом экране.

Резервная копия — скопировать `data/site.db` при остановленном сервере.

## API

- `GET /api/health` — проверка доступности.
- `GET /api/candles?visitor=ID` — `{"count":N,"mine":true|false}`.
- `POST /api/candles` — зажечь свечу. Тело: `{"visitor":"ID"}`. Ответ как у `GET`.
- `GET /api/votes?visitor=ID` — `{"tally":[[a,b],[a,b],[a,b]],"mine":[0|1|null, …]}`: число голосов за каждую версию трёх загадок и голоса посетителя.
- `POST /api/votes` — проголосовать. Тело: `{"visitor":"ID","riddle":0..2,"choice":0|1}`. Ответ как у `GET`.
- `POST /api/feedback` — сохранить отзыв. Тело: `{"message":"Текст отзыва"}`, максимум 1000 символов.

`ID` — 8–64 символа из латинских букв, цифр, `_` и `-`. Проверка: `npm test`.
