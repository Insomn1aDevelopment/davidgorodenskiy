# Давид Городенский

Фронтенд находится в `site/index.html` и включает стили и JavaScript в одном файле. Изображения лежат в `site/img/`.

Запуск из корня репозитория:

```sh
npm start
```

Откройте <http://localhost:3000>. Сервер и API находятся в `site/server.js`; описание API — в [site/README.md](site/README.md).

Сервер заранее кэширует HTML и изображения в памяти, сжимает HTML gzip и использует ETag для повторных запросов. Свечи памяти, голоса «весов истории» и отзывы хранятся во встроенной базе SQLite (`site/data/site.db`). Зависимостей npm нет; требуется Node.js 22.13 или новее.

Проверка API: `npm test`.

## Версия в одном файле

`npm run build` собирает `dist/index.html` — весь сайт в одном файле: фотографии и шрифты встроены внутрь, внешних ссылок нет. Его можно загрузить на любой хостинг, где разрешена одна HTML-страница, или просто открыть с диска. Без сервера всё работает, кроме общего счёта: свечи и голоса сохраняются только у посетителя. Для сборки нужен интернет (шрифты скачиваются с Google Fonts). После правок `site/index.html` пересоберите файл.

Методические рекомендации, презентация и речь для представления сайта лежат в `docs/`.
